## 一、赛题背景

Maximum 是逐元素二元算子，用于比较两个张量并保留较大值，常见于激活裁剪、边界约束和元素级融合计算。

## 二、算子功能描述

对输入张量 `x` 和 `y` 执行逐元素最大值计算：

```text
out = maximum(x, y)
```

当输入形状不一致时，需要按照 NumPy/PyTorch 广播规则计算。

## 三、输入输出与属性

| 类型 | 参数名 | 数据类型 / 类型 | 形状 | 说明 |
|------|--------|----------------|------|------|
| INPUT | x | float, int32 | 任意可广播形状 | 第一个输入张量 |
| INPUT | y | float, int32 | 与 x 可广播 | 第二个输入张量 |
| OUTPUT | out | 与输入一致 | broadcast(x, y) | 逐元素最大值 |

无属性参数。

## 四、核心约束

- `x` 和 `y` 必须满足广播规则。
- 输出 shape 为广播后的形状。
- 输出 dtype 与输入 dtype 一致。

## 五、精度要求

- float：相对误差和绝对误差按平台 float32 标准检查。
- int32：结果必须完全一致。

## 六、测试覆盖

- CPU cases 覆盖 float 同形状和 int32 三维广播。
- NPU cases 覆盖较大规模三维广播场景。
