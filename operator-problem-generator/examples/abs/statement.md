## 一、赛题背景

Abs 是常用的一元逐元素算子，用于计算张量每个元素的绝对值。本题要求在昇腾 NPU 上实现 Abs 算子。

## 二、算子功能描述

对输入张量 `x` 的每个元素计算绝对值：

```text
out = abs(x)
```

## 三、输入输出与属性

| 类型 | 参数名 | 数据类型 / 类型 | 形状 | 说明 |
|------|--------|----------------|------|------|
| INPUT | x | float, int32 | 任意形状 | 输入张量 |
| OUTPUT | out | 与 x 一致 | 同 x | 绝对值结果 |

无属性参数。

## 四、核心约束

- 输出 shape 与输入完全一致。
- 输出 dtype 与输入完全一致。
- 输入可能包含负数、零和正数。

## 五、精度要求

- float：相对误差和绝对误差按平台 float32 标准检查。
- int32：结果必须完全一致。

## 六、测试覆盖

- CPU cases 覆盖 float 矩阵和 int32 向量。
- NPU cases 覆盖较大规模 float 矩阵。
