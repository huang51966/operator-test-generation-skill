## 一、赛题背景

Equal 是基础比较算子，用于判断两个张量对应元素是否相等，常用于条件选择、掩码生成和验证逻辑。

## 二、算子功能描述

对输入张量 `x` 和 `y` 执行逐元素相等比较：

```text
out = (x == y)
```

输出为 bool 张量。当输入形状不一致时，需要按照广播规则计算。

## 三、输入输出与属性

| 类型 | 参数名 | 数据类型 / 类型 | 形状 | 说明 |
|------|--------|----------------|------|------|
| INPUT | x | int32, float | 任意可广播形状 | 第一个输入张量 |
| INPUT | y | int32, float | 与 x 可广播 | 第二个输入张量 |
| OUTPUT | out | bool | broadcast(x, y) | 相等比较结果 |

无属性参数。

## 四、核心约束

- `x` 和 `y` 必须满足广播规则。
- 输出 dtype 固定为 bool。
- 输出 shape 为广播后的形状。

## 五、精度要求

比较结果必须完全一致。

## 六、测试覆盖

- CPU cases 覆盖 int32 同形状比较和 float 广播比较。
- NPU cases 覆盖较大规模 int32 同形状比较。
