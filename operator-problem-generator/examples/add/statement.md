## 一、赛题背景

Add 是最基础的逐元素二元算子，用于张量加法、残差连接和偏置累加等场景。本题要求在昇腾 NPU 上实现支持广播的 Add 算子。

## 二、算子功能描述

对输入张量 `x` 和 `y` 执行逐元素加法：

```text
out = x + y
```

当 `x` 和 `y` 形状不完全相同时，需要按照 NumPy/PyTorch 广播规则计算输出形状。

## 三、输入输出与属性

| 类型 | 参数名 | 数据类型 / 类型 | 形状 | 说明 |
|------|--------|----------------|------|------|
| INPUT | x | float, int32 | 任意可广播形状 | 第一个输入张量 |
| INPUT | y | float, int32 | 与 x 可广播 | 第二个输入张量 |
| OUTPUT | out | 与输入一致 | broadcast(x, y) | 加法结果 |

无属性参数。

## 四、核心约束

- `x` 和 `y` 必须满足广播规则。
- 输出 dtype 与输入 dtype 一致。
- 支持同形状输入和一维广播输入。

## 五、精度要求

- float：相对误差和绝对误差按平台 float32 标准检查。
- int32：结果必须完全一致。

## 六、测试覆盖

- CPU cases 覆盖 float 同形状和 int32 广播。
- NPU cases 覆盖较大规模 float 同形状输入。
